# 局域网文件共享工具 - Web UI 重构设计

**项目**: SQ 局域网文件共享工具
**日期**: 2026-03-16
**版本**: 2.0

---

## 1. 概述

本文档描述了基于Web UI技术的全新界面设计方案，采用卡片式布局 + PyQt5 + QWebEngineView 实现现代化用户体验。

## 2. 设计选择

| 项目 | 选择 | 说明 |
|------|------|------|
| UI框架 | PyQt5 + QWebEngineView | 使用Qt内置浏览器控件承载Web界面 |
| 布局方式 | 卡片式布局 | 顶部状态栏 + 下方功能卡片 |
| 颜色主题 | 清新绿 (#10B981) | 主色调绿色，现代舒适 |
| 进度显示 | 完整型 | 显示进度条、百分比、速度、已传大小、剩余时间、文件列表 |

## 3. 技术架构

### 3.1 分层结构

```
┌─────────────────────────────────────────┐
│              Web 前端                    │
│  (HTML/CSS/JavaScript 独立界面)          │
├─────────────────────────────────────────┤
│           Qt WebChannel                  │
│      (前端与PyQt通信桥梁)                │
├─────────────────────────────────────────┤
│           业务逻辑层                     │
│  (network/, transfer/, config, file_handler) │
└─────────────────────────────────────────┘
```

### 3.2 通信机制

- 前端通过 `QtWebChannel` 与PyQt后端通信
- 后端暴露业务接口给前端调用
- 事件通过信号槽机制从后端推送到前端

### 4.2 卡片说明

1. **状态栏**: 显示本机IP、连接状态、对方设备名
2. **连接卡片**: 创建/加入房间、局域网房间列表、手动连接、配对码显示
3. **传输卡片**: 文件列表、添加/发送按钮、完整进度信息、下载目录
4. **日志卡片**: 操作日志显示

## 5. 功能模块

### 5.1 连接管理

| 功能 | 说明 |
|------|------|
| 创建房间 | 生成6位配对码，广播房间信息 |
| 加入房间 | 扫描局域网房间，双击或手动输入连接 |
| 手动连接 | 输入IP和配对码直接连接 |
| 断开连接 | 关闭当前连接 |

### 5.2 文件传输

| 功能 | 说明 |
|------|------|
| 添加文件 | 弹出文件选择对话框 |
| 添加文件夹 | 弹出文件夹选择对话框 |
| 清空列表 | 清除待发送文件 |
| 发送文件 | 开始传输选中的文件 |
| 进度显示 | 完整型进度信息 |
| 下载目录 | 设置/打开接收文件的目录 |

### 5.3 日志显示

| 功能 | 说明 |
|------|------|
| 自动记录 | 记录所有操作 |
| 时间戳 | 每条日志带时间 |
| 自动滚动 | 新日志自动滚动到底部 |
